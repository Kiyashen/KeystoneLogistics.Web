🚚 keystone Logistics
A modern logistics management platform designed to help businesses manage shipments, track deliveries, and coordinate transportation efficiently.

📋 About the Project
keystone Logistics is a logistics management system that provides businesses with an easy way to manage their deliveries and shipments.
The platform allows users to create shipments, track packages, manage drivers, and monitor delivery statuses from one central dashboard.

Live Link:
https://github.com/Kiyashen/KeystoneLogistics.Web.git

✨ Features
📦 Create and manage shipments
🚚 Track deliveries
👨‍✈️ Manage drivers
📍 View delivery locations
📊 Logistics dashboard
🔔 Delivery status updates
👤 Customer management
